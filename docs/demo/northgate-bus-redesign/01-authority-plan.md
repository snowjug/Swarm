# Northgate Transport Authority: network redesign plan

This is a fictional plan written for a scenario-simulation demonstration. All names, places and figures are invented.

## Usage

Bus ridership in 2025 was 8.2 million boardings across the network.

## The plan

The redesign would cost $48 million over five years. It would withdraw 11 low-ridership routes and run six main corridors every 10 minutes. Savings from the withdrawn routes would pay for part of the extra frequency.

## Timetable

The Authority would consult riders for three months and then decide whether to proceed.
