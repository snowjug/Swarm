# Reference parity matrix — Swarm Lab vs MiroFish

Swarm Lab is an **independent implementation inspired by** [MiroFish](https://github.com/666ghj/MiroFish)
(AGPL-3.0). No MiroFish code, assets, graph data, demo cases or prompts were copied; see
[NOTICE.md](../NOTICE.md). This matrix compares _observable, publicly documented behaviour_.

**Sources for the reference side:** the project README (workflow, overview, configuration), the repository
inspection recorded in [ARCHITECTURE.md](../ARCHITECTURE.md) (commit `7657031`, 26 Oct 2026), and the public
demo console, which its own entry page describes as a static demo without connected agent-chat inference.
Reference behaviour that is not publicly documented was **not** assumed.

**Legend.** BETTER and EQUIVALENT claims name their evidence; evidence is a test, a measurement, or a
document that can be re-run or re-read. _Model-assisted_ evidence is against scripted doubles and a
protocol-faithful **fake** provider unless a row says it was measured live (Azure `gpt-4.1-mini`, Entra only,
28 Oct 2026; see [AZURE.md](./AZURE.md#live-evidence)), and each row says which.

## Update: the live demo (28 Oct 2026)

A five-source synthetic scenario ([docs/demo/larkholm-ferry](./demo/larkholm-ferry/README.md)) was built end to
end through the real browser against the same Azure deployment: a 13-entity source graph whose quotes were
verified verbatim, six proxies on two platforms over six rounds with a stated reason for every decision, a
paused-and-resumed run with a scheduled intervention, a branch with a replaced intervention compared with its
parent, two reports with a grounding review (18 and 29 statements), an analyst chat, an actor chat, and Markdown
and JSON exports, with 0 console errors, 0 overflow and 0 axe violations at four viewports. That strengthens the
live evidence behind the graph, persona, simulation, report, branch, chat and export rows. It changes **no**
rating: it is still one small model and one scenario, and the live runs found reliability defects that are now
fixed and listed in [requirements-matrix.md](./requirements-matrix.md).

## Capabilities the reference does not document

The evidence-integrity program added capabilities that have no counterpart in the reference's public
material. They are **not rated**: with nothing to compare against, neither BETTER nor EQUIVALENT can be
supported. They are listed so a reader can see that the table above does not cover them, and each names its
evidence and its limits.

| Capability in Swarm                                                          | Evidence                                                                                                      | Limit                                                                                                      |
| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Statement types and support classes, with a deterministic publication policy | `backend/test/ledger.test.ts`, `ledger-service.test.ts`; [ADR 0001](./adr/0001-evidence-integrity-model.md)   | The checks are heuristics; the deterministic one accepted 3 of 8 unsupported statements in a labelled set  |
| Conflicts between sources, as candidates for a person to confirm or dismiss  | `backend/test/contradictions.test.ts`; `evaluation/`; [demonstration packs](./demo/README.md)                 | 1 of 3 labelled conflicts found; false alarms on some material; conflicts of meaning missed                |
| An analyst that declines without a model call, and must cite or decline      | `backend/test/evidence-gate.test.ts`, `demos.test.ts`; [ADR 0002](./adr/0002-abstention-and-citation-rule.md) | Refuses 43% (dev) and 86% (test) of unanswerable questions in the labelled set; 3 of 4 plausible ones pass |
| An assumption register                                                       | `backend/test/ledger-service.test.ts`; `e2e/model/ledger-ui.spec.ts`                                          | Derived and read-only                                                                                      |

## What this matrix does not claim

- No claim about the reference's undocumented internals, scale behaviour or prediction quality.
- No claim about model quality beyond the live measurements in [AZURE.md](./AZURE.md#live-evidence): one small model, three runs.
- No claim of visual or interaction-design superiority: that is a review judgement, not a measurement.
