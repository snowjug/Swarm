# Threat model: the production-candidate pilot

> **Status: a design-time model, written without a deployed system and without penetration testing.** Every
> "mitigation" is a control in code or in a template; every "test" is a file that exists in this repository. A
> mitigation that has no test is marked as having none. Nothing was attacked, scanned or run against Azure. This is not a
> security review and not a claim that the pilot is safe for the public: it is a **controlled pilot** for invited people, on
> infrastructure that has never been deployed.

It covers what is **new** with automatic research and with hosting: a service that **reads the open web on a person's
behalf**, asks a model to turn what it read into evidence, participants and constraints, and runs in Azure. What was
already modelled stays where it is and is not repeated: [the local single-user build](../threat-model.md), [the security
model](../security-model.md), [reading a public web page](../security/url-ingestion.md) (its own table of fetch threats).

## Scope, assets and boundaries

**Assets**, in the order a loss would hurt: the **evidence and the decisions** people put in (questions, pasted text,
uploaded documents; a decision's reasoning can be commercially or personally sensitive); **credentials and tokens** (the
managed identity's, a user's session, an Entra client secret if one is ever used); the **integrity of what Swarm says it
found** (a fabricated or altered source presented as retrieved evidence); the **credit** (a runaway model loop or crawl
costs money and, with a spending limit on, stops everything); **availability** of a pilot that cannot afford an outage
but cannot prevent one.

**Trust boundaries.** (1) Browser ⇄ ingress (public HTTPS; Entra sign-in). (2) Container ⇄ **the open web** (the
crawler: hostile by assumption). (3) Container ⇄ model endpoint (Entra token; the reply is untrusted text). (4) Container ⇄
PostgreSQL (Entra token, TLS; the database also holds every tenant's data). (5) Operator ⇄ Azure control plane
(`az`; a person with Contributor can do anything). (6) Build ⇄ registry ⇄ runtime (the supply chain).

**Assumptions.** Invited users only; one workspace per tenant boundary the application enforces; the Entra tenant's own
controls (MFA, conditional access, who may register apps) are the tenant owner's and are **not** configured here;
Azure's platform is trusted to isolate its customers.

## How to read the tables

- **S T R I D E E**: **S**poofing, **T**ampering, **R**epudiation, **I**nformation disclosure, **D**enial of service,
  **E**levation of privilege.
- **Tests**: a file that exists in this repository. A test of the application's code is evidence about that code with
  fakes and loopback servers, never about Azure; a row says so where the difference matters, and where a mitigation
  has no test it says that too.
- **Residual risk** is what remains _after_ the mitigation, stated plainly. "Mitigated, not solved" is a real answer.

## What this model does not cover

- **Anything about a deployed system**: no Azure resource exists. Platform behaviour (isolation, identity token
  handling, the ingress, the managed Postgres) is assumed, not examined.
- **Denial of service by volume** (a flood of requests). The ingress and the platform absorb some; an alert fires on
  request volume; there is no WAF, no rate limit at the edge, and no DDoS service beyond Azure's default infrastructure
  protection.
- **Content risks**: the truth, fairness or legality of what is read or generated; defamation; personal data in public
  pages (a person named in a page is stored as text). The product labels outputs as proposals; that is a label.
- **The tenant's identity controls** and **the owner's own workstation** (the `az` login and the release records live
  there).
- **A formal review.** Re-read this page when a control changes, when a new route or signal lands, and before the
  pilot is shown to anyone beyond the invited few. A mitigation whose only evidence is a test against a fake or a
  loopback server is not shown to hold in Azure.
