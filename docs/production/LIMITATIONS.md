# Known limitations of the production-candidate pilot

> **Read this before relying on anything else in `docs/production/`.** This is the list of things that are not true,
> not done, not measured or not checked, so that nobody mistakes an authored and compiled template for a running,
> tested, safe service. It is meant to be uncomfortable. Where a limitation has a cure, the cure is named; where the
> cure is a decision, the decision is named.

**What this deployment is:** infrastructure-as-code, release tooling and documentation for a **production-candidate
controlled pilot**: a few invited people, on a dev/test credit subscription, with an application that has never run in
Azure. **It is not a broad public production service and must not be described as one.**

## The application in this environment

| #   | Limitation                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Cure                                                                                                                                                                                                                                                             |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A1  | **One replica, always.** `maxReplicas` defaults to 1 ("keep 1 until several instances against one database have been validated"); `minReplicas` cannot be below 1 because the job runner is embedded and stops with the replica. **Several replicas against one database have not been validated**; the production-shaped profile keeps 1 too                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | Measure and test multi-replica behaviour (concurrency tests, the process-local limits below)                                                                                                                                                                     |
| A2  | **The PostgreSQL adapter is synchronous in appearance** (a worker and a bridge). **Its ceiling was measured only on a shared four-CPU VM against a local PostgreSQL 16 container, never against Azure**: about 10 project opens a second with the database 2 ms away and about 2 with it 20 ms away, and a busy process answers its health probe late ([database.md](./database.md#6-the-documented-load-ceiling)). The server cancels a statement after 30 s and the calling thread gives up after 35 s, after which the process is marked broken; nothing a person does cancels a running statement                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Measure again on a quiet machine and against the real server; the real fix, asynchronous stores with a pool, is a design change ([database.md](./database.md#13-what-would-raise-the-ceiling-and-what-has-not-been-done))                                        |
| A3  | **The application cannot run as a data-only database role today.** It migrates at startup with its own connection and runs `CREATE TABLE IF NOT EXISTS swarm_schema` on every start, so its role can create and change objects; and on a server the template creates **the identity is the server's Entra administrator**. A migration identity separate from a runtime identity needs an **application change** and then a template change ([runbook](./runbook.md#database-roles-what-the-application-needs-and-what-it-does-not-yet-allow))                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Add a migrate command and a verify-only runtime mode                                                                                                                                                                                                             |
| A4  | **The registry of fetched pages (provenance) is in memory.** After a restart, or on another replica, a real page counts as pasted text. That says less, never more, but it is lost                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Persist it, or accept it                                                                                                                                                                                                                                         |
| A5  | **Process-local limits.** The fetch limiter (8 at once, 8 queued) and the other in-memory counters are per process; they do not add up across replicas                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Share them (database or cache) before running more than one replica                                                                                                                                                                                              |
| A6  | **No search is switched on by default.** `RESEARCH_SEARCH_PROVIDER` is `none`, so a question alone ends `blocked` and waits for a source. Two providers are built and opt-in, each through the API its operator offers and never a page of results: `wikipedia` (no key; background pages, English only) and `brave` (a key, held as a Key Vault secret). A provider is sent the names and topics of the question, never the question as typed and with no reference number, key or figure in them, and answers with HTTPS addresses only, which the crawler vets like any other. **Neither has been run in Azure, `brave` has never been run against its real service (no key), and what either finds has not been evaluated:** `wikipedia` was run once against the real API (2026-11-04, one synthetic question, 6 addresses, 4 pages read) and found background that was only loosely about the question. "Researches the open web" is **not** what a pilot does until an owner chooses one                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | A provider chosen on cost, terms and data handling (`researchSearchProvider`): a decision, then a week of runs read by a person                                                                                                                                  |
| A7  | **Two revisions run two job runners** during the warm window. An older build may claim a job the newer one created. Untested ([release-process.md](./release-process.md#two-revisions-two-job-runners))                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | Keep warm windows short; test an old build against a new job                                                                                                                                                                                                     |
| A8  | **The application's controls on the crawler are the only controls.** No network egress filtering exists by default (NAT gateway and Azure Firewall are priced, and off). A flaw in the address policy has no second line of defence                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Decide on [controlled outbound](./azure-preflight.md#controlled-outbound-for-the-crawler-honestly) when the cost is acceptable                                                                                                                                   |
| A9  | **Copyright, terms of service and database rights of crawled content** are not addressed by any control                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | Owner and counsel                                                                                                                                                                                                                                                |
| A10 | **Model and data residency are not examined.** The existing model account may be in another region (East US 2) than the app (Central India); latency, data location and the data-processing terms of the model provider are not assessed                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Decide per customer and region                                                                                                                                                                                                                                   |
| A11 | **Product signals are partly wired, and none has been seen in Application Insights.** The participants proposal (`swarm.actors.*`), the constraint proposal and gate (`swarm.constraints.*`) and the duration of a comparison (`swarm.sim.duration`) are recorded by the code that does the work, as are the research signals, `swarm.model.*` and `swarm.deployment.info`; each is tested with in-memory exporters. Not recorded: `swarm.cancellations` for anything but research (a cancelled comparison, run or survey is not counted); the guided report's duration (`swarm.report.duration` is the Decision Canvas's); the regeneration of one participant and the older stakeholder discovery (`swarm.actors.*` counts the proposal); and a comparison that the server stopped ([privacy-telemetry.md](./privacy-telemetry.md#the-product-signals))                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Record the other cancellations and the guided report, or take them out of the catalogue; then check each in the [first-deploy queries](./observability.md#queries-to-run-once-after-the-first-deploy)                                                            |
| A12 | **What keeps an instruction out of the research plan reads patterns, not meaning.** In the evaluation's planner suite no question that carried a seeded instruction put its marker in a plan (0 of 5 in rules mode, 0 of 17 in fake-Foundry) and no corrupted reply was taken in (0 of 74), after a defect that the suite found was fixed: the rules' plan is made without the sentences that `models/injection.ts` reads as instructions, and a model's plan is refused if it repeats what one asked for. The guard recognises an instruction only where it has a pattern for it: one that asks for some text counts only when that text (a code-like token or a quoted phrase) follows the verb, and one that asks for nothing in particular only where it speaks to an assistant by name, so an instruction worded another way is planned from like any sentence; and a sentence that holds a real question and an instruction is left out whole, which the plan says. A plan holds no address and what is fetched is decided by code. A model's suggestion of a site the person wrote is still shown as the model's ([evaluation.md](./evaluation.md#what-the-evaluation-found-in-the-product))                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Widen the patterns from what a live model and real pages show, and keep precision 1 on the look-alike set (`evaluation/datasets/injection.json`); do not rely on the guard as the only control: what is fetched is code's decision                               |
| A13 | **Two quality thresholds are not met in rules mode, and the live mode has never run.** Participant coverage is 67.1% against 90% and hard-constraint recall 75.5% against 80%; what is left needs a model or a guess (roles the sources never mention, limits stated as bare quantities). A scripted model that answers from the labels reaches 99.4% and 89.8%, which shows what the checks keep and not what a model will find. There is no Azure authorization here, so no live evaluation exists                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | Run `npm run eval:ai:live` against a configured deployment. The thresholds are not edited to pass                                                                                                                                                                |
| A14 | **The scope check reads words, and the claim that Swarm does not decide about a person rests on it.** `backend/src/decision/scope.ts` reads the question and the scenario's own words by rules and puts a notice on the Decision view where one of five matters (employment, credit, legal, medical, safety) is touched; where an act of such a matter is said of one person it makes the status a human decision and names no option. Rules that read words cannot be complete: other phrasings are missed (“Is he well enough to be discharged?”, “Should I report my manager to HR?”, “What should we do about our employee who keeps stealing?”), other languages are not read, and a single capitalised organisation after _hire_ or _sue_ is read as a person, as is “hire a replacement for him”. The cue lists were written and widened against tables of questions by their own author (135 rows in `backend/test/decision-scope.test.ts`). Read through the check once, outside the evaluation (so not a recorded result), the 7 consequential requests of the evaluation's safety set were all read as about one person (3 of 3 on dev, 4 of 4 on test), but the 3 on dev are also rows of that author's table, and a sample of 7 says nothing about recall. Nothing at project creation or on the first screen reads the question, because the check runs when the Decision view is read; it never refuses; and the full report under the view is not changed by it and may still carry its own conditional recommendation. What does not depend on the words is the human-approval point: a qualified person's review is listed, and stays open, for any matter the check finds or a legal, regulatory or safety constraint names | Run the pilot's own questions through the check before a pilot and keep the misses on record (`NOT_CAUGHT` in `backend/test/decision-scope.test.ts`); decide whether a screen at the first step is wanted; keep the human-approval point whatever the check says |

## The platform

| #   | Limitation                                                                                                                                                                                                                                                                                                                            | Cure                                                              |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| P1  | **Single region, single zone, no high availability** in the pilot profile; PostgreSQL B1ms (Burstable) with 7 days of backups and **no geo-redundancy**. A region outage is an outage and, for the database, possibly data loss. The production-shaped profile turns on zone-redundant HA and geo-backup at about ten times the price | `production-shaped.bicepparam`, on a paid subscription            |
| P2  | **Public by default.** The ingress is public HTTPS (restrictable with `ingressAllowedCidrs`); the pilot database has a public endpoint with the "any Azure service" firewall rule, protected by Entra-only authentication and TLS. **Private networking is implemented, priced and off**, and compiled only                           | Turn on `enablePrivateNetworking`; verify it in a real deployment |
| P3  | **No web application firewall, no edge rate limiting, no DDoS plan** beyond Azure's default                                                                                                                                                                                                                                           | Front Door or Application Gateway: priced nowhere here            |
| P4  | **Container registry is Basic**: no geo-replication, no private endpoint, no zone redundancy, no content trust. Premium is in the production-shaped profile                                                                                                                                                                           | `production-shaped.bicepparam`                                    |
| P5  | **Key Vault is optional and unexercised**: the secret-reference path, rotation (a new revision resolves a changed secret) and the vault's purge protection (a deleted purge-protected vault keeps its name reserved for the 90-day soft-delete period) are untested. The default pilot needs no secret                                | Exercise it before relying on it                                  |
| P6  | **Entra: one tenant, one app registration, redirect URI added by hand** after the first deployment. MFA, conditional access and who may register applications are the tenant's, not configured here                                                                                                                                   | Tenant owner                                                      |

## What would have to be true to call it production

None of these is done. In order:

1. **Deploy it** and fix what Azure rejects; run the live smoke test; read the credit and the spending limit; confirm the
   subscription's terms allow the use. _(N1, N5, M1, M2)_
2. **Run the rollback drill (warm and `--cold`) and the database restore drill**, and keep the records. _(N2, N3)_
3. **Run the first-deploy observability queries**, fix the rules that read nothing, enable the crawler rule once
   the query shows its signal arriving, and **trip an alert** end to end. _(N4, A11, O2)_
4. **Separate the migration identity from the runtime identity** and test a data-only runtime role; **measure the
   database ceiling** on a real server. _(A2, A3)_
5. **Decide on outbound control, private networking and the public endpoints**; verify the choice in Azure. _(A8, P2)_
6. **Validate more than one replica**, or state a single replica as the design with a recovery objective. _(A1, A4, A5, A7)_
7. **Pin the base image and actions, add an SBOM, scanning and signing.** _(S1, S2)_
8. **Move to a paid subscription** with the production-shaped profile (zone-redundant HA, geo-redundant backup, private
   networking, 90-day logs), re-run steps 2 to 5 there, and keep the credit-subscription pilot as the rehearsal.
9. **An independent security review and a legal review of crawling and data handling.** _(O6, A9, A10)_

Until then the right words are: _a production-candidate controlled pilot, authored and validated offline, not deployed_.
