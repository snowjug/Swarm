| UI cannot reach backend                                                                         | Start both dev processes, check `/api/health`, and verify root `PORT`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| A banner says "The server's settings could not be read" or "Could not refresh this exploration" | The page could not reach the server just now. It keeps showing what it last loaded, and updates have paused (starting a question and model assistance wait too). Check that the server is running (`/api/health`), then choose **Retry**                                                                                                                                                                                                                                                                                                                                |
| A message says "That was not confirmed"                                                         | The server did not accept the action, and the message says why. The page has read what is saved again: look at how the project stands now, then try again                                                                                                                                                                                                                                                                                                                                                                                                               |
| A page says "Something didn’t render correctly."                                                | The interface met an error it could not recover from. Saved projects are held by the server: **Reload** reconnects, **Start over** returns to the first screen, and **Technical details** has the error to report                                                                                                                                                                                                                                                                                                                                                       |
| `EADDRINUSE`                                                                                    | Stop the specific prior app process or choose another port; do not kill unrelated Node processes                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| 403 host/origin                                                                                 | Add the exact trusted hostname/origin to its allowlist and restart; do not use a wildcard                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Model assisted** is disabled                                                                  | The line under **Options** on the first screen says why. Open the engine chip in the top bar to inspect the provider's status; configure model name, endpoint and required server-side key                                                                                                                                                                                                                                                                                                                                                                              |
| Model 401/404                                                                                   | Verify key, Azure deployment name, endpoint path and model/API compatibility                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Model `MODEL_REFUSED`                                                                           | The provider's content filter blocked a request; the message names the flagged categories. Review the text or the deployment's filter policy. No fallback is used                                                                                                                                                                                                                                                                                                                                                                                                       |
| Model `MODEL_PARAMETER_UNSUPPORTED`                                                             | The deployment rejected a request parameter (named in the message). Use a Chat Completions model that supports JSON output and `max_completion_tokens`                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Model 429/timeout                                                                               | Reduce agents/rounds, check provider quota or local inference capacity; errors remain visible. The scenario lab gives a model 170 seconds for one step (a reading, finding stakeholders, a review) and then carries on with rules and a note that says so. A CPU-only 3-billion-parameter local model took about five minutes for one scenario reading, so use a hosted or GPU-backed model for the lab's model steps                                                                                                                                                   |
| Azure `InsufficientQuota` while deploying                                                       | The subscription has no quota for that model and SKU in that region. Run `npm run azure:provision -- --subscription <guid> --list-models` to see candidates with real quota, name `--regions` and `--models` explicitly, or request quota in the portal                                                                                                                                                                                                                                                                                                                 |
| Model `MODEL_OUTPUT_INVALID` saying the reply repeated text from an embedded instruction        | A source passage contains an instruction aimed at an AI (the graph notes name the passage) and the model repeated its text; the reply was rejected on purpose. Remove or reword that line in the source. A document that quotes an injection phrase for a legitimate reason will trigger this                                                                                                                                                                                                                                                                           |
| Invalid model JSON/citation                                                                     | Use a model reliable at the documented structured schema; no fabricated fallback is returned                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| SQLite busy/sync problems                                                                       | Use one process and a non-synchronized local `DATA_DIR` (the startup log warns about OneDrive/Dropbox/Drive/iCloud paths, and `GET /api/config` carries the same warning as `storage.warning`; the interface does not show it); restore a known-good backup if needed                                                                                                                                                                                                                                                                                                   |
| Work marked failed after restart                                                                | Retry explicitly. A run that has a job in the queue survives a restart and continues (a simulation from its last saved round); only work that no job owned, such as a database from before the queue, is marked failed at start-up. A lab comparison is not a job: it is marked `interrupted` and is started again                                                                                                                                                                                                                                                      |
| Docker named-pipe error                                                                         | Start Docker Desktop/engine first; Compose parsing alone does not validate an image                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Export not appearing in an embedded browser                                                     | Open the app in a normal browser; embedded hosts may intercept downloads. Export HTTP payloads/attachments are independently tested                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Zod `@__PURE__` build warnings                                                                  | Current upstream comments produce two non-fatal Rollup annotation warnings; builds still validate                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `Unsupported engine` from `npm ci` or `npm install`                                             | Swarm needs Node.js 24 (`.nvmrc`, and `engine-strict` is on). Switch with your version manager and run the command again                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `Port 5173 is already in use` from `npm run dev`                                                | The Vite port is fixed (`strictPort`). Stop the other dev server, or the other process on 5173; the API port is `PORT`                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Fetch** (under **Evidence**, **Web page**) says the page could not be read                    | The message says why and offers to let you paste the text instead. `URL_BLOCKED`: not a public address (private, local and metadata addresses are never fetched). `URL_ROBOTS_DISALLOWED`: the site asks not to be fetched. `URL_NO_TEXT`: the page needs JavaScript. `URL_FETCH_FAILED` or `URL_TIMEOUT`: no network, or the site did not answer, or the name does not exist (a name that leads inside a network is answered the same way, on purpose). `URL_INGESTION_DISABLED`: the server has `URL_INGESTION=off`. See [URL ingestion](./security/url-ingestion.md) |
| A simulation says there are no simulated actors (`ACTORS_REQUIRED`)                             | On the **Map**, choose **Find who is affected**, then **Create actors**. Simulate says "No actors to simulate yet" until they exist, because a simulation needs the actors that approval makes                                                                                                                                                                                                                                                                                                                                                                          |
| The comparison warns that the change cannot move anyone                                         | No stakeholder has an expected direction of impact, so every difference from no change is noise. Say who is helped or harmed on the **Map** where your evidence supports it (the warning's **Review stakeholders** goes there), then run the simulation again. It never stops a run                                                                                                                                                                                                                                                                                     |
| **Compare**, **Decide** or **Simulate** stays locked after the earlier step finished            | The page reads a project's progress again while a comparison runs and until the brief is written, so these open by themselves. If one does not, choose **Refresh** under Settings and tools (the lock reason, "Needs actors" or "Run a simulation first", says what it waits for). **Simulate** opens once there are actors, and **Compare** and **Decide** once a comparison has finished                                                                                                                                                                              |
| **Ask about this** says "Ask opens with the report" in a project that has a brief               | The analyst and the actors answer from the deep dive's written report, so **Ask** opens once that exists. In the deep dive, **Prepare the environment**, **Start the simulation** and **Write the detailed report** each wait for the one before. The brief does not need any of them                                                                                                                                                                                                                                                                                   |
| **Read the text instead** is missing beside **Find who is affected**                            | It is offered only for a project made in **Model assisted** mode on a server with a configured provider, and then **Find who is affected** asks the model. Otherwise **Find who is affected** reads the text, which is always available                                                                                                                                                                                                                                                                                                                                 |
| The scenario review says "Read by rules, not a model" although a provider is set                | The question goes to a model only when **Model assisted** is chosen under **Options** before you choose **Explore** (the page sends `useModel`). With **Local rules** the rules on this server read it and it goes nowhere else. If a model was asked and did not answer in 170 seconds, or failed, the notes under **How it was read** say that the rules read it instead                                                                                                                                                                                              |
| The independent review says the project runs without a model (`MODEL_NOT_AVAILABLE`)            | The deeper review by a model is only for a project made in **Model assisted** mode on a server with a configured provider; the switch **Also ask a model** is disabled otherwise and the page says why. The deterministic review always runs                                                                                                                                                                                                                                                                                                                            |
| A comparison shows `interrupted`                                                                | The server stopped while it ran. It is reproducible from its seeds: start it again with the same settings                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `ANALYSIS_RUNNING` or `ANALYSIS_BUSY` when starting a comparison                                | One runs at a time for a project, and two at a time in a server. Wait for it, or cancel it                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `ARTIFACT_CONFLICT` when saving stakeholders, actors or a scenario                              | Someone changed the same document after you read it. Reload it and make the change again; nothing was overwritten                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Fetch** answers `URL_BUSY`                                                                    | The server is already reading as many pages as it allows for everyone together (by default 8 at once, with 8 more waiting up to 5 seconds). Wait a moment and try again, or paste the text instead. An operator can change `URL_INGEST_CONCURRENCY`, `URL_INGEST_QUEUE` and `URL_INGEST_QUEUE_WAIT_MS`                                                                                                                                                                                                                                                                  |
| `STAKEHOLDERS_NOT_APPROVED` or `ACTORS_OUT_OF_DATE` when starting a simulation                  | The stakeholders were found again or changed after the actors were made, so the comparison would simulate a cast that no longer matches them. On the **Map**, which says "The actors are out of date", choose **Make them again** (it asks first, and approves the list again if the change took the approval away), then run the simulation. The server's message says the same in words: make the actors again on the Map, then run the simulation                                                                                                                    |
| "This brief may be out of date"                                                                 | Something it rests on changed after it was made. If it names the scenario, the stakeholders or the actors, choose **Re-run the comparison**, which opens Simulate, and then **Write the brief again**; if it names only the review or a newer comparison, choose **Write the brief again**. "This review may be out of date" asks for the comparison, then the review, to be run again                                                                                                                                                                                  |
| `CRITIQUES_CHANGED` when answering a criticism                                                  | Someone else responded, or the review was run again, after you opened it. The page reads the review again and keeps the words you typed: read how it stands now, then send your answer again                                                                                                                                                                                                                                                                                                                                                                            |
| `EVIDENCE_ALTERED` or `EVIDENCE_NOT_VERIFIED` when saving the stakeholders                      | A quotation was rewritten, moved to another source or added. The Map shows quotations as they were read and does not change them, and the server refuses a changed or added one: reload the stakeholders and edit the other fields                                                                                                                                                                                                                                                                                                                                      |
| A chapter of the brief seems to be missing                                                      | The reference chapters (the assumptions, the evidence base, the sources, the limitations and the technical appendix) are closed until opened: use the contents, or **Open every chapter**. They are in the page, so find in the page reaches them                                                                                                                                                                                                                                                                                                                       |
| An end-to-end run stops with a port already in use                                              | Playwright does not reuse a server that is up. Move all nine `E2E_*_PORT` variables ([the testing guide](./TESTING.md#running-one-project-and-the-ports))                                                                                                                                                                                                                                                                                                                                                                                                               |

## This environment's npm registry mismatch

The project uses the official registry by default (approved for this workspace).
Here, its direct TLS handshake was unavailable. The existing Microsoft proxy was
reachable but returned tarball URLs under a different registry prefix, which npm
12 correctly rejected as disallowed remote packages. Installation succeeded by
mapping that registry prefix back to the **same trusted proxy**, without changing
TLS verification, remote-package restrictions, or install-script policy:

```powershell
npm.cmd ci --ignore-scripts --registry=https://packagefeedproxy.microsoft.io/npm/ --replace-registry-host=https://ms-feed-25.pkgs.visualstudio.com/1es-public/_packaging/npm-public/npm/registry
```

Use this only where that proxy is your approved registry. The lockfile retains
versions/integrity but omits environment-specific registry resolution URLs.
Do not solve connectivity problems with `strict-ssl=false`, token sharing, or
enabling disallowed dependency/script types.
